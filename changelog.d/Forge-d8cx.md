- **`forge warden consolidate` can now merge clusters** - Pass 1 spawned its AI session in the anvil itself, and Smith's pre-flight refuses any working directory that is inside a git repository without being a linked worktree — so on a real anvil (a main checkout by definition) every cluster failed before a provider was spawned and the pass reported itself as run having merged nothing. Pass 1 now runs in a throwaway detached worktree of the anvil's HEAD, removed on both the success and the failure path; the merged rule still comes back as JSON and is written to the anvil's own rules file. A worktree that cannot be created skips Pass 1 and is reported, rather than falling back to the arrangement that failed. (Forge-d8cx)
