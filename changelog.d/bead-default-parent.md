category: Added
- **Forge-created beads get a parent epic** - a new per-anvil `beads.default_parent` (with optional per-kind overrides under `beads.parents`) files every bead the Forge creates under that epic with `bd create --parent <id> --no-inherit-labels`: the consolidated dependency-update bead, vulnerability beads, Wicket issue beads, failed-quest beads, Forge-chat beads, ledger beads, and the follow-ups a smith files (its prompt now carries the flag). The team's bead rules require a parent epic, and beads without one do not show on the stand-up. Schematic sub-beads inherit the decomposed bead's epic. With the setting empty the bead is created as before and one warning per bead says it has no parent; the ledger also sends a blank type as `task`. Example: `heimdall: beads: default_parent: Heimdall-6tyq`.
