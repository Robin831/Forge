category: Changed
- **Byte-stable Assay prompt prefix across runs** - The opening region of every Assay pass prompt (preamble, repository guidance, change context, already-reported findings) is now rendered by one `stablePrefix` helper and depends only on the pull request and the checkout, so a second review of the same PR reads that prefix from the prompt cache instead of paying to write it again. The incremental framing and its baseline commit moved down to sit directly above the diff they describe, and the already-reported list is now sorted into a total order — by file, line, severity, title and a digest — with the 100-entry cap applied to that order rather than to whatever order SQLite returned the rows in.
