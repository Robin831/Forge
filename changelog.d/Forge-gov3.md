- **`forge bellows stop|resume <pr> --anvil <name>`** - Mute and unmute the Bellows PR monitor for a single pull request from the CLI. Stopping detaches the PR — no events, no automatic CI fixes, review fixes, rebases or Assay runs, and the fix workers already running for it are killed — while its mergeability and terminal state keep being tracked; resuming re-enables automatic work and drops the snapshot Bellows cached while it was muted, so problems that outlived the mute are re-detected as fresh transitions. The PR is addressed by its GitHub number scoped by `--anvil`, external `ext-*` PRs included, and one that cannot be resolved is refused rather than reported as muted. (Forge-gov3)
