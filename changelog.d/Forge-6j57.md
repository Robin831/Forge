- **Per-pass USD ceiling for Assay reviews** - A review pass session now carries a spend ceiling (`assay.max_cost_per_pass_usd`, default $1.50, `0` disables). Assay prices each turn from the usage the provider streams — one API message however many content-block events carry it, so a tool-using turn is billed once rather than two or three times — and stops the session once the running total reaches the ceiling, reporting the pass as failed with the new `error_max_cost` stop reason — which surfaces in the pass result, the run's status text, the per-pass telemetry and the PR summary comment exactly as `error_max_turns` does, never as a quietly short review. What the stopped session already cost is still counted. (Forge-6j57)
