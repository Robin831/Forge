- **Assay prompt-cache accounting on the run record** - Each Assay run now records the prompt-cache tokens its sessions wrote and read (`assay_runs.cache_creation_tokens` / `cache_read_tokens`, added by migration and defaulting to 0 on existing rows), on the failed path as well as the successful one — a run that died was still billed for the prefixes it wrote. The daemon's `Assay review completed` line carries the same totals as `cache_w` / `cache_r` plus `cache_w_redundant`, the write tokens a run paid for more than once, so a lost shared prefix is visible in a log line and a trend across a PR's runs is a query. (Forge-7a72)
