category: Added
- **`forge preview start` CLI verb** - Start a Kiln preview from the terminal with `forge preview start <bead-id> --anvil <name> [--branch <branch>]`, symmetric with `preview list`/`preview stop`: it waits for the daemon's queued outcome, prints the entry URL on success, and reports a refusal (previews disabled, no manifest, concurrency cap full) as the daemon phrased it. The bead id is a registry key rather than a bd lookup, so ad-hoc smoke previews of a branch with no bead — conventionally `kiln-smoke-<n>` — no longer need a hand-written IPC message. (Forge-l5fm)
