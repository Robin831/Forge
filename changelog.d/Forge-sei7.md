category: Added
- **Kiln preview manager** - Kiln now has a manager that owns running previews end to end: a bead→preview registry, the `preview_max_concurrent` cap (a start over the limit is rejected with a clear error rather than queued), the detached worktree plus manifest `setup`/`teardown` lifecycle around the service runtime, and last-active tracking for the idle reaper. Any failure after the preview checkout exists unwinds completely — services killed, teardown run, checkout removed, state row deleted — so a broken start never strands a worktree or a port range. Setup and teardown output is appended to `~/.forge/logs/<beadID>/preview.log`. (Forge-sei7)
