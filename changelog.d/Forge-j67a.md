category: Fixed
- **Burnish post-Smith pipeline can no longer hang silently** - Added a configurable verification timeout (`burnish_verify_timeout`, default 5m) around the post-Smith temper step in both `burnish.Fix` and `burnish.BatchFix`, plus transition logging tagged with `PR #<n> bead=<id>` at each step (smith exit, verification start/result, push start/complete, thread resolution start/complete). On verification timeout the worker row is transitioned to `failed` with the stable reason `warden_timeout` so the daemon's normal recovery path can re-dispatch instead of leaving the row stuck `running`.
