category: Fixed
- **Burnish post-Smith pipeline can no longer hang silently** - Added a configurable verification timeout (`burnish_verify_timeout`, default 5m) around the post-Smith temper step in both `burnish.Fix` and `burnish.BatchFix`. On timeout the worker is transitioned to `failed` and the stable reason `warden_timeout` is recorded in the event log and returned error so the daemon's normal recovery path can re-dispatch instead of leaving the row stuck `running`. Includes transition logs tagged with `PR #<n> bead=<id>` at each post-Smith step (smith exit, verification start/result, push start/complete, thread resolution start/complete), plus regression tests covering the "temper never returns" scenario for both Fix and BatchFix.
