category: Fixed
- **Shutdown orphan sweep no longer kills unrelated Claude processes** - The startup orphan sweep previously killed any process whose command line merely contained the substring "claude", terminating the operator's own Claude Code session on every daemon restart. Process ownership is now verified positively from the workers table (PID + start time) and the process working directory (must resolve inside a Forge worktree), and a lost-worker fallback requires an exact argv[0] basename match plus the same cwd check. No process is ever signalled on a cmdline substring alone. (Forge-uh8x)
