category: Fixed
- **Bellows no longer adopts non-Forge PRs that merely reference a bead** - PR ownership is now established by an explicit `<!-- forge-managed: true -->` marker embedded in the PR body when Forge creates it. Previously a contributor's manual PR (or any PR template / `Closes` reference) that contained `**Bead**: <id>` was adopted with `bellows_managed=true`, causing Bellows to push review-fix commits and attempt auto-merge against PRs Forge had no business touching. PRs without the marker are still tracked for display but are stored as `ext-<number>` and excluded from bellows lifecycle workers. (Forge-m1ui)
