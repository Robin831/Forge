category: Fixed
- **The rebase worker no longer force-pushes over others' commits, or after `forge bellows stop`** - Smith pushed the rebased branch itself, told to retry with a plain `git push --force` if `--force-with-lease` failed, so a commit a lane pushed while the rebase ran could be overwritten, and a stop did not prevent the push. Now Smith only rebases; Forge pushes, leased to the head the PR branch had when the job started (a push made meanwhile makes it fail), and skips the push when the PR's bellows is stopped. A worktree behind origin is fast-forwarded first so the rebase carries every pushed commit; one that has diverged from origin is refused.
