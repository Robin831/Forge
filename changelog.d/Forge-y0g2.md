category: Changed
- **Warden category filter maps .ts/.tsx to every canonical category** - `categoriesForFile` used to fold `.tsx`, `.ts` and `.css` into the same narrow `{ui, style, other}` set, so a frontend-scoped learned rule categorised `security`, `performance`, `error-handling`, `concurrency` or `testing` was dropped by the category filter on any frontend-only diff — `aggregateCategories` unions the per-file sets, so a diff touching only `.ts`/`.tsx` files never contributed those categories at all. TypeScript is a full application language, not just a styling surface, and the ext-682 warden batch re-scoped its frontend rules to `**/*.ts`/`**/*.tsx`, which left three of them inert: `markdown-image-render-untrusted` (security), `split-on-collapsed-preview` (performance) and `date-parse-fallback` (error-handling). `.ts`/`.tsx` now map to all canonical categories; `.css` stays `{ui, style, other}`, since a stylesheet really is a styling surface only, and `*_test.tsx` still resolves to `{testing, other}` through the early return above the switch. (Forge-y0g2)
