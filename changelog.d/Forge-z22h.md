category: Fixed
- **Worker log modal streams live smith output** - The `/api/worker/{id}/log` and `/stream` endpoints no longer 404 when a smith's log file hasn't yet hit disk; the tail returns `200 []` and the SSE stream keeps the connection alive until the file appears, so opening the modal on a running smith now shows entries within ~2s instead of getting stuck on "reconnecting…". The tail handler also drops trailing partial lines so a mid-write record isn't surfaced as a half-formed entry. (Forge-z22h)
- **Bellows worker cards are no longer clickable** - Workers list now tags each row with a `kind` (`smith` or `bellows`); the Hearth WorkersPane renders bellows PR-monitor rows as static info cards so clicking them no longer opens the log modal that errored with "invalid worker ID". (Forge-z22h)
