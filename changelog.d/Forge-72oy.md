- **Assay `files=` telemetry and retry diff scoping** - The Assay pass tracker recorded a file only from a `file_path`-shaped tool input, but measured over 95 pass sessions every one of 742 tool calls was `Bash` — so `files=` was 0 on every logged pass and the turn-budget retry's third modification (the diff scoped to the files the failed session opened) was never constructed. Paths are now also read from shell command lines (including git's `<rev>:<path>` form, input redirection and a quoted `sh -c` sub-command) and from the `path`/`notebook_path` input keys; `files=` counts only the names that look like a file, so a directory argument cannot report a pass that opened nothing as having read code, and only files already in the diff can be selected for a retry's scope — a bare basename matching two of them narrows nothing rather than pointing at the wrong package.
