category: Fixed
- **Forge restart script handles dirty `.beads/issues.jsonl`** - The daemon continuously rewrites `.beads/issues.jsonl` in `~/source/Forge`, so the restart script's `git pull` always aborted with "local changes would be overwritten by merge", making Hytte's Mezzanine "Rebuild & Restart" button a silent no-op. The script now stashes only `.beads/issues.jsonl` (pathspec-limited) before pulling, records the specific stash ref to avoid dropping unrelated stashes, and aborts if any other tracked files are dirty. Added `scripts/restart.sh` as the in-repo source-of-truth so future fixes don't drift from the deployed copy at `~/.forge/restart.sh`. (Forge-b82c)
