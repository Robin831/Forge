category: Fixed
- **The Smelter no longer replaces an open batch PR** - a regeneration of `forge/warden-learn-batch/<anvil>` reset the branch to main and force-pushed, so the rules an open batch PR had learned were dropped without being archived, its review threads pointed at rules that no longer existed, and fix commits pushed to the branch were erased. Now a branch with an open PR is built on and pushed without force (a push that is not a fast-forward fails and keeps the queue); a branch with no open PR and commits main lacks (a closed batch, or no PR) is pushed to `<branch>-replaced-<sha>` before it is replaced; and when the PR state cannot be read the flush stops rather than replace.
