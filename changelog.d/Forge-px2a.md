- **Wedged-anvil detection** - The daemon now checks each anvil once per full poll for a beads (Dolt) working set left mid-merge with unresolved conflicts, a state in which every `bd` write against that anvil is silently rolled back. A wedged anvil is surfaced in Needs Attention naming the conflicted table(s), the conflict count and the branch divergence (`ahead N / behind M`), logged at WARN while it persists, and skipped for dispatch — manual dispatch is refused with the real reason instead of accepted and discarded. The entry clears itself once the conflicts are resolved; no operator dismissal. Detection only: resolving the merge stays a human decision. Disable with `settings.anvil_health_check: false`. (Forge-px2a)
