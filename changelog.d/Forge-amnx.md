category: Added
- **Per-anvil settings in the Settings page** - The Settings page now renders a section per registered anvil with its own toggles. Tri-state keys (schematic_enabled, golangci_lint, go_race_detection, depcheck_enabled, questgiver_enabled, wicket_enabled) use an Inherit / On / Off control so "follow global" is distinguishable from an explicit override, while plain bools (auto_merge, wicket_auto_dispatch) stay two-state. Values are read from GET /api/forge/config and written via PATCH /api/forge/config/anvils/{name}, with the "applies on next run" note shown for non-hot-reloadable keys. (Forge-amnx)
