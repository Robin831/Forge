category: Fixed
- **Stranded-branch recovery recognizes language-split changelog fragments** - The completion-signal check (`branchHasChangelogFragment`, used by both auto stranded-branch recovery and `forge queue create-pr`) only matched `changelog.d/<bead>.md`. Repos that split fragments by language — e.g. Munin's `changelog.d/<bead>.en.md` + `<bead>.nb.md` — failed the check, so completed work whose PR was never opened could neither auto-recover nor be recovered via `create-pr`; it stranded in needs_human (Fhi.Metadata-15ed9). The check now also accepts the dot-delimited `<bead>.<lang>.md` form (without matching a different bead whose id shares a prefix). (Forge-clfr)
