category: Changed
- **Assay resolves providers per pass** - Each Assay pass (triage and the five deep passes) now resolves its own provider chain: anvil `stage_providers["assay.<pass>"]`, anvil `assay`, global `assay.<pass>`, global `assay`, then the legacy `assay.triage_provider`/`triage_model` and `review_provider`/`review_model` keys, then the provider defaults. It never inherits `smith_providers` or `providers`, and with no assay stage keys every pass runs on exactly the provider it did before. The daemon logs one warning per anvil that sets both a legacy key and an assay stage key, naming which one decides each pass, and `forge doctor` prints the resolved chain and its source for every pass of every Assay-enabled anvil. (Forge-iyddo)
