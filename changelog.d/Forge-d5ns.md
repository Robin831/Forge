category: Fixed
- **Provider auth failures no longer loop forever** - Invalid/expired credentials (exit code 2 with auth stderr) are now classified as authentication failures instead of rate limits, so a misconfigured API key escalates to Needs Attention with a clear "check API key/credentials" message rather than retrying and failing over across providers indefinitely. Bare exit code 2 with no corroborating rate/quota phrase is no longer treated as a rate limit. (Forge-d5ns)
- **Consistent gate fail policy** - The copilot daily-request filter now fails closed on a DB error (mirroring the daily-cost gate) and never hands the caller an empty provider list. When the cap is overshot because copilot is the only provider, a `copilot_limit_hit` event is recorded so the situation is visible. (Forge-d5ns)
