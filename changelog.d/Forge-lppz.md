category: Added
- **Idle preview reaper** - Kiln now tears down previews that have gone untouched for longer than `preview_idle_timeout`, so a preview an operator opened and walked away from stops holding a worktree, a slice of the preview port range and one of the `preview_max_concurrent` slots. The sweep runs on a ticker derived from the timeout and stops cleanly on daemon shutdown; a timeout of 0 disables it. (Forge-lppz)
- **Startup reconciliation of orphaned previews** - Previews left behind by a crashed daemon are cleaned up on startup: recorded service process groups are killed, the detached checkout is removed and the state row is deleted, and any `<anvil>/.previews/` directory with no live preview behind it is pruned. A recorded PID is only signalled once the live process is positively identified as that preview's service (process start time, plus the working directory where the platform exposes one), so a recycled PID is reported and left alone rather than killed. (Forge-lppz)
