category: Fixed
- **Assay turn-budget retries no longer re-send identical inputs** - A pass that ended on `error_max_turns` was re-run with a byte-identical prompt, giving the second session exactly as much reason to spend its whole budget exploring as the first — so a partial run cost roughly twice a complete one and usually failed anyway. The re-run now carries a halved turn budget (floored at 3 turns), an explicit instruction to answer now from what the session already has, and a diff scoped to the changed files the failed session actually opened. The assembled payload is hashed against the original and the retry is dropped rather than paid for if the two match, in which case the run reports partial coverage and the daemon's Assay log line reads `retry=skipped`. A spend-ceiling stop (`error_max_cost`) is never retried at all. (Forge-tl5z)
