category: Changed
- **The Forge image carries stock bd v1.3.2** - bd is no longer built from the Robin831/beads fork: the image downloads upstream's v1.3.2 release and checks it against its sha256, the same binary Varde runs. dolt-beads moved to schema 66 on 03.11.2026, which the fork's bd 1.1.2 refuses ("schema version mismatch"), so a Forge on the old image cannot read beads until it runs this image. The release build has CGO, so the embedded store still works. The release workflow no longer resolves the fork's main, and it checks the baked bd against the Dockerfile's BD_VERSION.
