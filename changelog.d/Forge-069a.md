category: Changed
- **Skybert image moved off the release critical path** - The full `-skybert` devbox image (dolt + bd + claude + ttyd) and the forgeBench devbox dispatch now run in a separate `post-release-images.yml` workflow triggered by the Release run completing, instead of inline in `release.yml`. Releases no longer wait on a fat image that is not a release artifact, and a skybert build failure surfaces as its own red run without marking the release failed. The published tag is unchanged (`ghcr.io/robin831/forge:<tag>-skybert`); it just lands shortly after the release rather than as part of it, and can be rebuilt on demand with `gh workflow run post-release-images.yml -f tag=vX.Y.Z`. (Forge-069a)
