- **Smelter Pass 3 narrows over-broad rule paths** - The paths backfill skipped every rule whose Paths field was already populated, and after a rule has been through it once it always is, so the pass was a no-op on every rule that exists — this repository's own 727-rule file holds not one rule with an empty Paths field. It now also compares: where the globs derived from a rule's own source PRs are strictly narrower than the ones on file, and still match at least one file of those PRs, the rule is re-gated — so a Go rule carrying `**/*.md` because the PR that taught it also touched a doc stops joining the Warden checklist on documentation-only diffs. A rule whose current paths admit nothing narrower costs no PR lookup, and narrowings are counted and committed apart from fills, since a rule whose Paths were never empty was not backfilled. Measured over two real rules files: 60 of 727 rules narrowed on this repository's own (12.1% to 9.5% of rules carrying three or more repo-wide globs) and 750 of 2295 on a multi-language one (67.6% to 37.9%).
