category: Fixed
- **Smelter paths backfill is rule-aware** - Backfilled Warden rule `paths` are now derived from the language the rule's own pattern/check text names, intersected with the extensions the source PR touched, instead of every extension the PR happened to include. A Go rule learned from a mixed Go+frontend PR no longer carries `**/*.ts`/`**/*.md`, which had made the path-glob filter stop narrowing anything. The language signals are language-unique tokens only — bare prose words (`nil`, `defer`, `chan`, `props`) are not signals, since they attribute language-agnostic rules to Go — and an inference the source PR's own files contradict is discarded in favour of those files, so a misfire can never leave a rule gated on a language its diffs never contain. A directory glob (`changelog.d/**`) is additive to the PR-derived set rather than a replacement for it, and is kept only when the source PR actually touched a file it matches. Rules whose text names no language keep the old PR-derived set. (Forge-w0f6)
