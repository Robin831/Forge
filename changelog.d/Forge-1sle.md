- **Munin (Assay) AI PR review — shadow-mode rollout** - The Assay post-PR code reviewer ships as a complete, end-to-end feature and is rolled out in shadow mode: when enabled via the `assay` config section (`enabled: true`, `shadow_mode: true`), Bellows triggers a multi-pass AI review over a managed PR's head and writes deduplicated findings to the `pr_findings`/`assay_runs` tables **without** any public side effects (no PR comments, no thread resolution) so the engine can be observed safely before posting is turned on. Shadow mode is the conservative default (`shadow_mode` defaults to true). The findings surface in Hearth 2.0 — the PRs page gains a per-PR findings panel with live SSE updates and a Re-run button — and over the IPC/CLI surfaces via the `assay_rerun` command, `forge assay run --pr N --anvil A`, and a per-pass `forge doctor` provider-availability check.
