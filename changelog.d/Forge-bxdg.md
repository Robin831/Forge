category: Changed
- **Burnish and quench verification is gated on the PR's changed files** - Review-fix and CI-fix verification now hand Temper the file list the branch actually changed (same base-ref derivation the pipeline uses: the PR's base branch, else origin/main, else origin/master), so steps with `paths` globs are skipped when nothing they cover moved. Recomputed per verification attempt, reused by the post-timeout retries, and fail-open — an unreadable diff runs every step, as before. Skipped steps are named in the burnish/quench logs so a skip is distinguishable from a pass. (Forge-bxdg)
- **Auto-detected Temper steps carry default `paths` globs** - Go, .NET and subdirectory Node steps are now gated out of the box (`**/*.go`/`go.mod`/testdata/`.golangci.*`, the C#/MSBuild/Razor/appsettings/`global.json`/fixture set, and `<dir>/**` respectively), so a one-line frontend change on a mixed-stack repo no longer runs the whole backend build and test suite. A Node project at the repository root stays ungated, and explicit `temper.steps` are unchanged. (Forge-bxdg)
- **Go step gating covers `//go:embed` targets** - Embedded assets (prompts, templates, a built web bundle) are build inputs with no extension in common, so the Go detector scans the worktree for `//go:embed` directives and gates its steps on what they name. Without it a PR touching only `internal/assay/prompts/*.md` skipped build, vet and test and reported PASS. A scan that cannot complete — an unreadable or oversized `.go` file included — leaves the Go steps ungated rather than gating on a partial list, and symlinked `.go` entries are never opened, so a contributor branch carrying `x.go -> /dev/zero` cannot make the scan read without bound. (Forge-bxdg)
- **Reconciled PRs record their base branch** - PRs registered by the reconcile loop (external PRs, and forge-authored rows lost from state.db) now persist the base branch the platform reports, so changed-file gating and the rebase path resolve against the PR's real base instead of falling back to `origin/main`. (Forge-bxdg)
- **Changed-file lists name every path a diff touches** - The diff behind path gating now passes `--no-renames`, so a move is reported as both its old and new path and deleting the last file under a gated directory still triggers the steps that covered it. (Forge-bxdg)
