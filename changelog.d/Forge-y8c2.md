category: Changed
- **Assay repeat reviews are now incremental** - A PR that was already reviewed gets its next review scoped to the changes since the last reviewed commit (with automatic fallback to a full review after a force-push/rebase, and a skipped run when the delta touches nothing in the net diff), every pass prompt now lists the already-reported findings so the model does not restate them, the top-level summary is a single per-PR comment edited in place instead of one new comment per run, the `nit_cap` budget is cumulative across the PR's review history, a new `max_findings_per_pr` cap (default 30) bounds total findings of every severity, cross-run dedupe now also catches reworded findings whose anchors drifted far (same file + category) and resolved findings that regenerate, and a failed run no longer marks its head as reviewed. New config: `assay.incremental` (default true), `assay.max_findings_per_pr` (default 30). (Forge-y8c2)
