category: Changed
- **Stage-named worker log files** - Each pipeline stage (schematic, warden, quench, burnish, rebase, assay) now writes its Claude session log with a stage-identifiable prefix (e.g. `warden-<ts>.log`) instead of the generic `smith-<ts>.log`, so preserved per-bead transcripts under `~/.forge/logs/<beadID>/` reveal which stage produced each file. (Forge-udzk)
- **Full Temper output persisted** - Temper now writes the complete, untruncated build/lint/test output of every step to `temper-<ts>.log` in the worktree log directory, which is preserved alongside the stage logs — making failed-test forensics on finished beads possible. (Forge-udzk)
