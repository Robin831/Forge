- **Schematic panels stream their session instead of dying on "reconnecting…"** - Schematic recorded its temp-workdir log path (`/tmp/forge-schematic-*`) on the worker row; the Hearth log allowlist rejected it, the stream answered 400 — which permanently closes the browser's EventSource — and the temp dir (log included) was deleted when the session ended, so the finished panel had nothing to tail either. The session log is now written straight to the caller's durable log dir (the worktree's `.forge-logs`, or `~/.forge/logs/<bead>` for the daemon's crucible check), and the stream endpoint treats an invalid path on a still-active worker as "no path yet" and waits instead of 400ing.
