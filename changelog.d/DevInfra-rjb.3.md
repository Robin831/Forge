category: Fixed
- **A dependency bump no longer runs against the anvil's old packages** - a worktree shared the anvil's node_modules whenever the anvil had one, and Temper refuses npm ci on a shared folder, so a branch that moved package-lock.json was checked with the old packages (Fhi.Metadata-9huq2.11 went needs-human this way). A worktree now shares the anvil's install only when npm's record of what is installed (node_modules/.package-lock.json) matches the worktree's lockfile; otherwise it is left unlinked, or a reused worktree's stale link is removed, and the install step installs in the worktree. Without a lockfile to compare, it shares as before; previews, which have no install step, still share and log a warning. An anvil whose Temper has no install step (unlike the forge chart's anvils, which run npm ci in client/) gets no node_modules in a worktree while the anvil's install is behind the lockfile.
