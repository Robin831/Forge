- **Beads-Forge bead emission** - The Hearth 2.0 /forge page can now turn a settled design session into one or more beads. Stage=ready surfaces a "Create bead(s)" button that runs claude in a structured-emission mode, validates the proposal (cycles, cross-anvil deps, unknown anvils, bad types/priorities), then materialises the beads via `bd create` in each anvil's directory with sibling depends_on edges wired through `--deps`. If any bd subprocess fails partway, all previously-created beads are rolled back via `bd close --reason="rollback: ..."` so the session is left in a clean state. (Forge-7968)
