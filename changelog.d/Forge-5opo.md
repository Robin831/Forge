- **Assay partial-run state** - An Assay review where some passes covered the head and others did not now reports a distinct `partial` status instead of a bare failure. The run record persists the pass tally and the failed passes with their reasons, the worker row carries its own amber `partial` chip (with `partial: N of M passes completed (failed: logic, repo-specific — error_max_turns)` in the daemon log, the `assay_partial` event and the PR findings panel), the finished worker panel lingers with its log like every other terminal status, and the PR summary comment opens with a line naming the passes that did not review this head — so a short findings list is never mistaken for full coverage.
