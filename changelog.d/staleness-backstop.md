category: Added
- **Staleness backstop for per-anvil checkers** - Forge records when depcheck, vulncheck, questgiver and PR reconcile last completed a cycle for each anvil, and reports one that has gone quiet for more than three of its own intervals. It reads no error classification at all, which is the point: it exists for the case where a failure was classified transient and retried silently, so consulting that classification would blind it to exactly the fault it is there to catch. A completed cycle withdraws the entry by moving the timestamp — there is no state to clear or re-arm.
- **PR reconcile failures leave a trace** - a per-anvil reconcile that could not list open PRs previously logged a warning and moved on, persisting nothing. It now registers the anvil, so an anvil whose reconcile has failed on every cycle since startup becomes visible instead of silently never running.
