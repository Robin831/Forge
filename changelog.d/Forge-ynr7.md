category: Added
- **Run E2E quests against a preview** - New per-anvil `preview_quests` setting (default `false`, and rejected at load time unless previews are enabled for the anvil) opts an anvil into running its QuestGiver quests against a running Kiln preview. Quest steps expand `{{.BaseURL}}` against the preview's entry URL instead of the quest file's fixed `url`, the run only happens while the preview is healthy, and its result is tagged with the preview ID and head SHA so reporting can stay idempotent. (Forge-ynr7)
- **`{{.BaseURL}}` expansion in quest files** - Quest step `url` and `value` fields now resolve `{{.BaseURL}}` (the quest's own `url` on a scheduled scan) rather than being sent to the browser literally; a quest file whose template does not parse is skipped with a logged error instead of failing as if the application were broken. (Forge-ynr7)
