- **Assay skips PRs with nothing reviewable in them** - A review whose diff carries no hunks once generated files and the anvil's `assay.skip_paths` have been filtered out now records a skipped run and dispatches none of its six sessions, instead of paying triage plus five deep passes to review an empty diff. The skip is reported rather than hidden: `assay_runs.skipped_reason` records it, the PR summary comment says the review was skipped instead of "no issues found", the activity feed row reads `skipped: no reviewable changes` instead of `0 findings`, and no existing review thread is aged toward auto-resolution on the strength of a run that read no code.
