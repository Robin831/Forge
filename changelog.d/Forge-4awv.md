category: Changed
- **Temper robustness: bounded output, configurable timeouts, failure classification** - Temper now caps each step's combined stdout+stderr with head+tail truncation and an elision marker (default 256 KiB via `temper_output_cap`), so a verbose test suite can no longer balloon memory or the warden/fix prompt. The default per-step timeout is configurable via `temper_step_timeout` (default 5m, per-step timeout still overrides) and internal git calls via `temper_git_timeout` (default 30s). Step failures are now classified (test_failure / build_error / timeout / infra); the pipeline retries timeout and infra failures once without invoking the Smith, then escalates to needs-attention with the classification instead of looping the Smith on a phantom failure. A step killed by daemon shutdown or IPC interrupt (a cancelled context) is no longer mistaken for an infra failure — the pipeline aborts cleanly and leaves the bead open for retry instead of escalating it to needs-attention. (Forge-4awv)
