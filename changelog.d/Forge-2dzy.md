- **Per-child `independent` label** - A child of a parent that opted into epic orchestration (`crucible`/`epic-branch:<name>`) can now carve itself back out with an `independent` label: the Crucible never claims it or its subtree, it is not stamped with the epic branch (worktree from main, PR to main) and it is not withheld from the ordinary dispatch loop, so tagging it `forgeReady` runs it standalone alongside the epic. It is excluded from the epic's completeness set entirely — its work could never land on the feature branch, so an open independent child no longer holds up the epic's final PR — and the queued-children event names the beads it excluded. The label is inert on beads that are not children of an orchestrated parent, and wins over an opt-in label on the same bead. (Forge-2dzy)
