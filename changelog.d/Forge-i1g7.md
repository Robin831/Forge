category: Fixed
- **Per-instance forge-managed marker for multi-forge deployments** - The `<!-- forge-managed: ... -->` marker Forge embeds in PR bodies now carries the forge instance id (`<!-- forge-managed: <id> -->`) sourced from `settings.forge_id` or the host name. Sibling Forge instances pointing at the same anvil no longer race to adopt each others' PRs. (Forge-i1g7)
- **Reconcile re-evaluates already-tracked PRs** - `reconcileOpenPRs` no longer short-circuits with `continue // already tracked`. Each open PR's body is re-checked against the current instance's marker on every pass, so PRs adopted under the legacy logic (any `**Bead**:` in body, or the pre-i1g7 generic marker) automatically have `bellows_managed` flipped off without manual `state.db` edits or pod resets. The reverse promotion (false → true when the marker arrives) is also supported. (Forge-i1g7)
