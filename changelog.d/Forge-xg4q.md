category: Added
- **Detached preview worktrees for Kiln** - `worktree.CreateDetached` / `RemoveDetached` materialize and tear down a preview checkout of a worker branch under `<anvil>/.previews/<beadID>`. The checkout is detached at the branch tip (fetched from origin, falling back to a local-only ref), so a preview can be created while the worker's own worktree still holds the same branch, and re-creating over an existing preview lands at the current tip. `.previews/` is git-ignored and the worker worktree lifecycle is untouched; no preview runtime is wired up yet. (Forge-xg4q)
