category: Fixed
- **A review fix that makes no commit resolves no thread** - when the review-fix smith exits without a new commit, because `forge bellows stop` killed it or because it changed nothing, burnish ends the cycle there: no verification, no push, no thread resolved, and the PR keeps its review-needs-fix state. The error is `ErrBellowsStopped` after a stop, else the new `ErrNoNewCommit`. Before, «HEAD matches origin» was taken as «Smith already pushed», so a stop during a fix could resolve the threads with no fix on the PR (DevInfra #175, 2026-10-12). A stop after Smith has pushed a real fix still counts the fix, as since #945. (Fhi.Metadata-srl7z)
