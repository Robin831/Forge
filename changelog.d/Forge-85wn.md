category: Added
- **Settings page: numbers, dropdowns & text fields** - The Hearth 2.0 Settings page now exposes non-boolean settings, not just on/off toggles. Global scalars (max total/lifecycle smiths, retry limits, daily cost limit, merge strategy, Warden sample rate, Wicket batch size) and per-anvil scalars (max smiths, auto-dispatch mode/tag/min-priority, VCS platform) render as validated number inputs, dropdowns, and text fields driven by API-provided schema metadata. The config API GET now returns per-key type/options/min/max and a per-anvil key schema; PATCH validates typed values (range, enum membership, integer-ness) and persists them while preserving comments. (Forge-85wn)
