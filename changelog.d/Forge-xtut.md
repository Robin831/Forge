category: Changed
- **Bounded self-deploy drain wait** - Self-deploy now pauses dispatch and retries the worker drain check on a ticker for the whole `self_deploy.max_drain_wait` window (default 30m) instead of giving up on the first busy sample, so a deploy triggered while a Smith is mid-run lands in the first gap that opens. On expiry the deploy is deferred with a `self_deploy_skipped` event naming the elapsed time and the beads that held it up. The pause is undone on every non-restart exit path, so a failed deploy cannot leave dispatch paused. The former `self_deploy.drain_timeout` key is still read as a deprecated alias. (Forge-xtut)
