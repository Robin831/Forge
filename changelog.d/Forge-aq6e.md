category: Added
- **Host-based preview routing** - With `settings.preview_proxy_base` set, Hearth 2.0 now serves Kiln previews on wildcard subdomains: `<label>.<base>` reaches a bead's entry service and `<label>--<service>.<base>` one of its named services, forwarded to the preview's allocated port with the request untouched (same path, query and Host header; SSE, HMR and websocket upgrades all pass through). Browsing a preview counts as activity, so the idle reaper leaves it alone, and a host naming no live preview answers 404 saying which state it is in. Traffic on any other host — the dashboard's own included — is unaffected. (Forge-aq6e)
