category: Fixed
- **Kiln preview port range no longer collides with the Linux ephemeral range** - The default `preview_port_range` moves from `42000-42999` to `24000-24999`, below every common ephemeral port floor. A port inside the kernel's ephemeral range (Linux `net.ipv4.ip_local_port_range`, typically `32768-60999`) could be handed to an outbound connection between Kiln allocating it and the preview service binding it minutes later, killing the service with "address already in use". A configured range that overlaps the host's ephemeral range now logs a WARN naming both ranges at daemon start — warn only, so existing configs keep working. (Forge-ai74)
