category: Added
- **Ad-hoc previews from the Hearth previews page** - The `/previews` fleet page now carries a small form — preview id, anvil, optional branch — that starts a Kiln preview for a branch no worker owns, the browser half of `forge preview start`. The id is a registry key rather than a bd lookup, so an ad-hoc smoke preview (conventionally `kiln-smoke-<n>`) of any branch no longer needs the CLI, and leaving the branch blank keeps the daemon's `forge/<preview-id>` default. The preview start endpoint now forwards an optional `branch` in its request body to make that possible. (Forge-hruc)
