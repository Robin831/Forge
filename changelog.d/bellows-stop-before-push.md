category: Fixed
- **A review fix no longer pushes over others' commits, or after `forge bellows stop`** - the review-fix push fetched and then pushed `--force-with-lease`, so the lease was whatever the branch held at push time and a commit a person or a lane pushed while the fix ran was overwritten; and a fix already running when `forge bellows stop <pr>` was given could still push before the worker was killed (PR 6723, 2026-10-16). Now the push is a fast-forward only: origin's branch must be an ancestor of the fix, otherwise the push is refused and the commit is kept in the worktree for a person. A reused worktree is fast-forwarded to origin before the fix starts, so Forge's own earlier push is no reason to refuse. Just before pushing (a verified fix, or one pushed unverified after its verification timed out), the fix checks the PR's stop flag and, when set, keeps the commit instead of pushing it. The push now sends `HEAD`, not a local branch of the same name. `forge pause` is unchanged.
