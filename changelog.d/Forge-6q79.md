category: Added
- **Run quests from the Hearth preview panel** - The bead-detail preview panel gains a "Run quests" action for anvils that opted into `preview_quests`, offered only while the preview is healthy. The run is dispatched asynchronously (`POST /api/bead/{id}/quests` answers 202 with a run id) and the panel polls it, showing the overall status, a row per quest with its failing step and message, and thumbnails of any screenshots captured. Results are purely informational — no pipeline stage, Bellows check or merge gate reads them, and the panel says so next to a failure. (Forge-6q79)
- **`preview_quest_run` / `preview_quest_status` IPC commands** - Dispatch and poll an on-demand quest run against a bead's live preview. A refused run answers with a machine-readable reason (`not_enabled`, `not_healthy`, `no_preview`, …) rather than an error, so a client can tell a closed gate from a broken daemon. (Forge-6q79)
