category: Added
- **Preview cap behaviour: rejection by default, opt-in LRU eviction** - Starting a Kiln preview while `preview_max_concurrent` is reached is still refused rather than queued, but the error now names the limit *and* the beads holding the slots, so the answer says which preview to stop. The new `settings.preview_evict_lru` setting (default `false`) trades that refusal for stopping the least recently used preview to make room; a preview whose start is still in flight is never evicted, and an automatic preview (`preview_auto: ready_to_merge`) never evicts anything — it is skipped when the box is full, as before. (Forge-p4eo)
